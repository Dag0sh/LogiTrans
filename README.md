# LogiTrans: Система управления логистикой грузов

Это iOS-приложение на SwiftUI, интегрированное с PostgreSQL базой данных, для управления грузами, клиентами, сотрудниками и пунктами выдачи. Приложение поддерживает разные роли пользователей: от клиентов (отслеживание грузов) до руководителей (полный доступ ко всем функциям). База данных управляется через SQL-процедуры, триггеры и представления для обеспечения целостности данных.

## Описание проекта

LogiTrans — это мобильное приложение для логистической компании, позволяющее автоматизировать процессы отправки, отслеживания и управления грузами. Основные компоненты:

- **Фронтенд**: iOS-приложение на SwiftUI с экранами для входа, управления сущностями и отчётов.
- **Бэкенд**: PostgreSQL база данных с таблицами для клиентов, сотрудников, пунктов выдачи, грузов и отгрузок.
- **Интеграция**: Приложение подключается к БД через библиотеку `PostgresClientKit` (в файле `NetworkManager.swift`). Все запросы асинхронные, с обработкой ошибок.

### Основные сущности в базе данных (из `script_golikov_a_08.sql`):
- **Client**: Клиенты (телефон, адрес, ФИО, пароль).
- **Point**: Пункты выдачи (название, телефон, адрес).
- **Employee**: Сотрудники (ФИО, позиция, телефон, пароль).
- **Cargo**: Грузы (трек-номер, тип, доставка, отправитель/получатель, цена, масса, стоимость, упаковка, страховка).
- **Shipments_golikov_a_08**: Отгрузки (связь с грузом, пункт, слот, статус, сотрудник, дата).

### Функции приложения:
- **Вход**: Раздельный для сотрудников (`LoginView.swift`) и клиентов (`ClientLoginView.swift`). Проверяет credentials через БД.
- **Роли сотрудников** (в зависимости от позиции в `Employee`):
  - **Руководитель** (`LeaderView.swift`): Доступ ко всем ролям через вкладки (Оператор, Админ, Склад, Отчёты, Трекинг).
  - **Администратор** (`AdminView.swift`): Управление грузами, клиентами, пунктами, сотрудниками (создание, обновление, удаление через процедуры).
  - **Оператор** (`OperatorView.swift`): Создание грузов и отгрузок, расчёт цены (функция `calculate_total_price` в БД).
  - **Работник склада** (`WarehouseView.swift`): Управление отгрузками (обновление слотов, статусов, архивация при доставке).
  - **Менеджер** (`WarehouseLoadView.swift`): Просмотр загруженности складов (вью `v_warehouse_load`).
- **Клиентские функции** (`ClientTrackingView.swift`): Отслеживание статуса груза по трек-номеру (вью `v_cargo_status`).
- **Отчёты**: Доходы и статистика (вью `v_reports_income`).
- **Дополнительно**: Триггеры для проверки слотов и обновления дат, процедуры для CRUD-операций, тестовые данные в SQL-скрипте.

Приложение использует SwiftUI для UI (с фокусом на клавиатуре, анимациями, списками), асинхронные задачи для сетевых запросов и обработку ошибок с "дружественными" сообщениями.

### Технологии
- **Фронтенд**: SwiftUI, Swift 5+.
- **Бэкенд**: PostgreSQL (с процедурами, триггерами, функциями и представлениями).
- **Интеграция**: PostgresClientKit для подключения к БД.
- **Дополнительно**: DateFormatter для дат, NumberFormatter для чисел, асинхронные Task для сетевых операций.

## Установка и запуск

### Требования
- Xcode 15+ (для iOS 17+).
- PostgreSQL 14+ (установленный локально или на сервере).
- Устройства (симулятор или реальные iOS-устройства) в одной сети с PostgreSQL-сервером.

### Шаги по установке
1. **Клонируйте репозиторий**:
   ```
   git clone <your-repo-url>
   cd LogiTrans
   ```

2. **Настройка PostgreSQL**:
   - Создайте базу данных: `CREATE DATABASE logitrans_golikov_a_08;`.
   - Подключитесь к базе как пользователь с правами (например, `dagosh` с паролем `1008`).
   - Выполните SQL-скрипт `script_golikov_a_08.sql` для создания таблиц, процедур, триггеров и тестовых данных:
     ```
     psql -U dagosh -d logitrans_golikov_a_08 -f script_golikov_a_08.sql
     ```
   - В файле `postgresql.conf` (обычно в `/etc/postgresql/<version>/main/`):
     - Установите `listen_addresses = 'localhost'` или конкретный IP (уберите `*` для безопасности).
   - В файле `pg_hba.conf` (там же):
     - Добавьте в конец строку для разрешения подключений: `host all all 0.0.0.0/0 scram-sha-256` (или ограничьте по IP для безопасности).
   - Перезапустите PostgreSQL: `sudo systemctl restart postgresql`.

3. **Настройка приложения**:
   - Откройте проект в Xcode: `open LogiTrans.xcodeproj`.
   - В файле `NetworkManager.swift` укажите IP-адрес вашего PostgreSQL-сервера в строке `config.host = "172.20.10.2"` (замените на актуальный, например, `192.168.1.100` или `localhost` для локального тестирования).
   - Убедитесь, что устройства (симулятор/телефон) и сервер в одной сети.
   - В `Info.plist` уже настроен `NSLocalNetworkUsageDescription` для доступа к локальной сети.

4. **Запуск**:
   - Соберите и запустите в Xcode (Cmd + R).
   - Выберите роль на главном экране (`ContentView.swift`): "Сотрудник" или "Клиент".
   - Для тестирования используйте тестовые данные из SQL-скрипта (например, сотрудник: телефон `+79161111111`, пароль `pass1`; клиент: `+79161234567`, пароль `clientpass1`).

### Возможные проблемы и решения
- **Ошибка подключения**: Проверьте IP в `NetworkManager.swift`, firewall (откройте порт 5432), и конфиг PostgreSQL. Логи ошибок выводятся в консоль Xcode.
- **Ошибки в БД**: Если процедуры не срабатывают, проверьте логи PostgreSQL. Убедитесь, что пользователь имеет права на выполнение (GRANT EXECUTE).
- **Тестовые данные**: SQL-скрипт вставляет 3 клиента, 3 пункта, 5 сотрудников, 3 груза и 3 отгрузки для демонстрации.
- **Безопасность**: В продакшене используйте SSL (`config.ssl = true`), ограничьте `pg_hba.conf` по IP и не храните пароли в коде.

## Использование

1. **Вход**:
   - Сотрудник: Введите телефон и пароль. Перенаправит на экран роли.
   - Клиент: Аналогично, перенаправит на отслеживание.

2. **Основные сценарии**:
   - **Создание груза** (Оператор): Заполните поля, рассчитайте цену, выберите пункт — создаст запись в `Cargo` и `Shipments`.
   - **Управление отгрузками** (Склад): Выберите пункт, обновите статус (при "доставлено" — архивация).
   - **Администрирование**: CRUD для всех сущностей.
   - **Отчёты** (Менеджер): Просмотр загруженности складов.
   - **Отслеживание** (Клиент): Введите трек-номер — покажет историю статусов.

3. **Отчёты и вью**:
   - `v_cargo_status`: Статусы грузов.
   - `v_reports_income`: Доходы по периодам.
   - `v_warehouse_load`: Занятость слотов.

Проект демонстрирует интеграцию мобильного приложения с реляционной БД, с акцентом на безопасность данных (проверки в триггерах) и удобный UI.
